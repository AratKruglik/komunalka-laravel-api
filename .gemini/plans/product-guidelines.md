# Product Guidelines: Komunalka

## Prose & Communication
- **Tone:** Professional, direct, and user-centric. Avoid jargon where possible.
- **Language:** Primary interface in Ukrainian. Use consistent terminology (e.g., 'лічильник' instead of 'вимірювач').
- **Error Messages:** Clear, actionable, and helpful. Explain what went wrong and how to fix it.

## Branding & Visual Style
- **Color Palette:**
    - **Primary:** Gold (#FFD700) as the main accent color.
    - **Secondary:** Violet (#8b5cf6) for supporting elements.
    - **Accent:** Emerald (#10b981) for highlights.
    - **Links:** Goldenrod (#DAA520) with DarkGoldenrod (#B8860B) on hover.
- **Typography:**
    - **Main Font:** Montserrat (sans-serif) for all interface text.
    - **Mono Font:** UI Monospace for technical data.
- **Icons:** Consistent set from Lucide React.

## UX Principles
- **Simplicity:** Minimize the number of clicks required for common tasks (e.g., adding a meter reading).
- **Responsive Design:** Optimized for both desktop and mobile use (essential for on-site meter readings).
- **Feedback:** Provide immediate visual feedback for all user actions (e.g., success toasts).
- **Accessibility:** Adhere to WCAG 2.1 AA standards for inclusive design.

## Technical Documentation
- **API Responses:** Consistent JSON structure with proper error codes.
- **Comments:** Use clear, concise comments in the code to explain complex logic.
- **Readme:** Maintain a comprehensive and up-to-date README.md for developers.
