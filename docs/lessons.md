# Lessons

## 2026-10-20: Ownership of HatkoBot code

- Перед плануванням нового сценарію перевіряти не лише поточні маршрути й залежності, а й те, якому модулю належить функція. HTTP Actions, Form Requests, сторінка, fallback і тести ХаткоБота мають жити в `Modules/Ai`; `Modules/Shared` не є домом для AI-функції лише тому, що так розміщено старий код.
- Під час перенесення між модулями зберігати зовнішні URL, route names і JSON-контракт, а потім шукати залишкові `Modules\\Shared` посилання на ХаткоБота та проганяти маршрутні/функціональні тести.

## 2026-10-12: Laravel AI SDK support agent

- Перед проєктуванням AI-функції викликати налаштований Laravel Boost MCP (`application-info`, `search-docs`) і звіряти встановлену версію SDK з офіційним upgrade guide.
- Якщо користувач просить агента з інструментами, реалізувати окремий клас `Agent` та SDK `Tool`; попередня схема retrieve-before-prompt не виконувала цю вимогу.
- Перевіряти сумісність міграцій та існуючих розмов перед major-оновленням SDK; не замінювати застосовану міграцію без плану перенесення даних.
- Після оновлення SDK перевіряти перейменовані ключі конфігурації: `models.embedding.default` став `models.embeddings.default`. Однакова розмірність векторів не робить різні embedding-моделі сумісними.
- SDK `continue()` не авторизує власника UUID; перед ним потрібна явна перевірка `VerifiesConversationOwnership`.
- Для дорогого tool-calling чату одразу встановлювати ліміти запитів, кроків, токенів і паралельності; додавати тест на видалення історії після видалення акаунта.
