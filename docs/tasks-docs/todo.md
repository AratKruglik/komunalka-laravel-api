 Інтеграція Swagger / OpenAPI Документації

## Обраний пакет: `dedoc/scramble`
Для сучасних Laravel-проєктів (особливо на PHP 8.4 та Laravel 12) найкращим рішенням є **Scramble**. 
Він генерує Swagger/OpenAPI документацію **автоматично**, аналізуючи Form Requests, API Resources, PHP-типізацію та DocBlocks. Вам практично не потрібно буде писати багаторядкові `@OA` анотації, що збереже чистоту коду.

Альтернативою є `darkaonline/l5-swagger` (вимагає ручного написання анотацій над кожним методом та класом), але Scramble економить десятки годин розробки і краще підходить для вашого стеку з жорсткою типізацією.

## План інтеграції (Scramble)

- [ ] Встановити пакет `dedoc/scramble` через Composer (`composer require dedoc/scramble`).
- [ ] Опублікувати конфігурацію пакета (`php artisan vendor:publish --provider="Dedoc\Scramble\ScrambleServiceProvider" --tag="scramble-config"`).
- [ ] Налаштувати `config/scramble.php` (вказати шляхи до модулів, якщо маршрути знаходяться в `Modules/`).
- [ ] Налаштувати авторизацію для перегляду документації (доступ для розробників/адмінів на продакшені через Gate).
- [ ] Перевірити роботу UI (зазвичай за адресою `/docs/api`) та експорту JSON (`/docs/api.json`).
- [ ] Додати інструкції щодо генерації і перегляду в README.md (за потреби).

## План перевірки (Verification)
- Переконатись, що сторінка `/docs/api` відкривається.
- Переконатись, що `/docs/api.json` віддає валідний OpenAPI (Swagger) JSON формат.
- Перевірити, що всі ендпоінти з `Modules/*/routes/` потрапили у фінальний JSON.
