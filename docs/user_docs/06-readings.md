# 6. Показання

Показання вносяться **пакетно**: за один раз — для всіх лічильників однієї адреси, з автоматичним розрахунком споживання та вартості.

## 6.1 Внесення показань (`Внести показання`)

1. **Оберіть адресу** — типово підставляється ваша основна адреса; сторінка покаже картку для кожного лічильника обраної адреси. Якщо на адресі немає лічильників, з'явиться підказка «Немає лічильників для вибраної адреси» з порадою додати їх у розділі «Лічильники», а кнопка «Зберегти» буде неактивною.
2. **Заповніть картки лічильників.** Кожна картка містить:
   - **Попередні показання** (лише для читання) — останнє внесене показання або початкове значення лічильника;
   - **Поточні показання** — поле для нового значення;
   - **Дату зняття** — типово сьогодні, можна змінити;
   - **Фото** — можна прикріпити фото лічильника як підтвердження (JPEG, PNG, WebP, HEIC/HEIF).
3. Під час введення система **наживо рахує**:
   - споживання = поточні − попередні показання;
   - вартість = споживання × ставка тарифу (якщо у лічильника є провайдер із тарифом);
   - підсумкова таблиця внизу показує загальні суми.
4. Натисніть кнопку збереження — після успіху ви потрапите до історії показань із повідомленням **«Показання успішно збережено!»**

### Багатотарифні лічильники

Якщо провайдер лічильника має кілька тарифів (наприклад, «День» і «Ніч» для електроенергії), картка лічильника покаже **окреме поле показань для кожного тарифу**. Попереднє значення відстежується окремо по кожному тарифу.

### Правила валідації

- Показання **не може бути меншим за попереднє** — сервер відхилить збереження з повідомленням «Значення показника не може бути менше попереднього.»
- Показання не може бути від'ємним.
- Дата зняття обов'язкова.
- Тариф підставляється автоматично: береться тариф провайдера, чинний на дату зняття показань.

## 6.2 Історія показань

Сторінка «Показання лічильників» (відкривається після збереження) вимагає **обрати адресу** зі списку — навіть одразу після збереження показань адресу треба обрати знову. Показання відображаються картками:

- назва лічильника та серійний номер;
- дата зняття, поточне й попереднє значення, споживання;
- бейдж **«Оцінка»** для розрахункових (не фактичних) показань;
- примітки та мініатюри фото — клік по фото відкриває повнорозмірне зображення в новій вкладці;
- кнопка видалення показання (з підтвердженням).

> Для багатотарифного лічильника в історії буде окремий запис на кожен тариф, але **назва тарифу (День/Ніч) у картці не показується** — записи розрізняються лише значеннями.

Поки прикріплені фото обробляються, показується індикатор обробки; сторінка оновлюється автоматично кожні 4 секунди до завершення.

## 6.3 Видалення показання

Показання можна видалити з історії: діалог «Видалити показання?» → «Видалити» → flash «Показання успішно видалено.» Редагування показань не передбачено — якщо припустилися помилки, видаліть хибне показання і внесіть правильне.

> **Увага:** система не забороняє внести кілька показань на ту саму дату. «Попереднім» завжди вважається останнє за датою показання відповідного лічильника (і тарифу).
