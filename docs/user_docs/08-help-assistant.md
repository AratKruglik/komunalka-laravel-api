# 8. Help and KhatkoBot

**KhatkoBot** is a built-in assistant that answers questions about using Komunalka and provides links to the relevant sections.

> In the current build, the assistant is sometimes still called by its old name "КомуШІшка" (on the help page title, widget) — this is a leftover from an incomplete renaming; functionally it is the same assistant.

## 8.1 Floating Chat Widget

The round chat button in the bottom-right corner is available **on all pages** after login. Clicking it opens a chat window with:

- a greeting from KhatkoBot;
- quick question chips (e.g., "How do I submit a reading?", "Managing meters", "Choosing a provider", "How are tariffs calculated?");
- an input field: **Enter** to send, **Shift+Enter** for a new line;
- a "Start new conversation" button (resets history) and a "Open full help page →" link.

The window can be closed with the "Close" button or the **Escape** key.

## 8.2 The "Help" Page (`/help`)

A full-screen version of the chat plus two additional cards:

- **"What you can ask about"** — topic shortcuts that navigate to the relevant section: Submitting readings, Meters, Providers, Addresses;
- **"Documentation"** — quick links: Quick start, Submitting readings, Tariffs and calculations.

## 8.3 How the Assistant Works

- Ask a question in your own words — the assistant will recognize the topic (readings, meters, providers, addresses, tariffs, payments) and respond with a short explanation.
- **Source cards** appear below the response — clickable links to the relevant section of the application.
- The assistant's responses are marked with an "AI · Response generated by our AI" badge.
- If the topic isn't recognized, the assistant will respond: "I don't yet know the exact answer to this question. Try browsing the dashboard or use one of the suggestions above." along with a link to the Dashboard.

## 8.4 Limitations

- Questions are limited to 1000 characters; no more than 60 questions per minute.
- Conversation history exists only within the currently open page — after a reload, the chat starts over.
- The paperclip (attachment) button in the input field is currently decorative — files cannot be sent.
- The assistant only answers typical questions about the app's sections; it cannot see your data (readings, tariffs) and does not perform actions on your behalf.
